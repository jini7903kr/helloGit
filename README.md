### Enable GitHub Pages (one-time, required)

Agent tokens cannot turn Pages on for this repo. An owner must do this once:

1. Open [Settings → Pages](https://github.com/jini7903kr/helloGit/settings/pages)
2. **Build and deployment → Source**: Deploy from a branch
3. Branch: `main` · Folder: `/ (root)` → Save
4. Wait ~1 minute, then open the URL above
