1. 채점이 바뀐 핵심

최종 = (기술점수 × 연결 배율) + 예술점수 − 감점

예전에는 같은 심판이 “무엇이 나왔는가”와 “얼마나 잘했는가”를 같이 봤습니다. 2.0은 기술팀(식별)과 품질 심판(품질)으로 나눕니다.

2. 예전 vs Classic 2.0

항목예전Classic 2.0
기술 만점대략 60에서 막힘상한 없음
연결(풋워크)기술 점수 안에 섞임기술 전체에 곱함 (0.95~1.25)
예술기술 ±10 가이드에 묶이기 쉬움기술과 분리, 3항목
후반거의 없음약 90초 이후 ×1.10
심판한 패널이 식별+품질기술팀 + 품질 심판

4. 심판 포지션 변화

기존2.0달라진 점
채점 심판품질 심판기술 식별 대신 QoE·연결·예술만
(없음)스페셜리스트기술 이름·속성·수준을 부름
계산 심판데이터 오퍼레이터실시간 입력·리뷰 운영
치프품질 심판 겸임기술 콜은 기술팀

기술팀

  • 스페셜리스트: 콜
  • 어시스턴트: 검증·감점 기록
  • 데이터 오퍼레이터: 입력
  • 컨트롤러(선택): 펜 교차검증

품질 심판

  • QoE −3~+3 (기술마다)
  • 연결 0~5 → 배율
  • 예술 3요소 각 0~10
  • 기술 이름·속성은 바꾸지 않음

5. 편성

최소 4명

스페셜리스트 + 어시스턴트 + 데이터 오퍼레이터 + 품질 1

완전 7명

+ 컨트롤러 + 품질 3(평균). 치프는 품질 중 1명
