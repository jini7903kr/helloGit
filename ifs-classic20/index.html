채점 규정 · 심판 안내

PRO Skate Classic 2.0(시험 규정)을 심판·운영 기준으로 정리한 공개 안내입니다. 선수 A/B/C 훈련 전략은 이 페이지에 없습니다.

중요
이 문서는 World Skate 공식 룰북이 아닙니다. 원문은 시험 중인 규정입니다. 공식 World Skate 규정: worldskate.org

한 줄 공식

최종 = (기술점수 × 연결 배율) + 예술점수 − 감점

심판은 “무엇이 나왔는가”와 “얼마나 잘했는가”를 나눕니다. 난도 값은 트릭 카드가 정하고, 품질 심판은 QoE·연결·예술만 매깁니다.

포지션별 해야 할 일

스페셜리스트

  • START/END로 평가 구간
  • 콜 순서: 간격 → 기술 → 속성 → 수준 → 콤보
  • Base / Under / Tap / Cancel / Review
  • QoE·예술·연결 점수는 주지 않음

품질 심판

  • 기술마다 QoE −3~+3
  • 연결 0~5 → 배율
  • 예술 3요소 각 0~10
  • 기술 이름·속성을 바꾸지 않음

어시스턴트 · 데이터 오퍼레이터

  • 콜 검증 / 리뷰 영상
  • 실시간 입력과 상태 관리
  • 종료 후 낭독·감점 반영

편성

  • 최소 4명: 스페셜리스트·어시스턴트·데이터·품질1
  • 완전 7명: +컨트롤러 +품질3(평균)
  • 치프는 품질 심판 중 1명 겸임
