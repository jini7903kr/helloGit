# 인라인 프리스타일 클래식 2.0

PRO Skate System의 프리스타일 슬라럼 채점 규정(클래식 2.0, v.2, 2026년 11월 4일)을 한국어로 옮긴 룰북이다. 조항을 찾아 읽고, 기술 카드의 실제 가산점을 보며, 한 기술의 점수를 제6.2조 순서대로 계산하고, 기존 Classic 대비 심판 포지션 변화도 같은 페이지에서 볼 수 있다.

이 문서는 World Skate 공식 룰북이 아니다. 원문은 시험 중인 규정이라고 스스로 밝힌다.

## 로컬에서 보기

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:4317` 을 연다.

## 원문

- 규정: https://proskatesystem.base44.app/Regulations
- 트릭 수치는 같은 시스템에 공개된 기술 카드(2026년 11월 17일)를 `src/data/tricks.json`에 담아 두었다.
